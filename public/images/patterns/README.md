These patterns use glyph outlines from Aref Ruqaa (SIL Open Font License 1.1), generated by a script kept outside the repo.

- `*.v2.svg` (in use): letters plus simple location symbols (map pin, radar arcs, crosshair, signal waves), about 1 shape in 8. The symbols are plain geometric shapes drawn by the script.
- `*.v1.svg`: letters only; kept for now, no longer referenced.
